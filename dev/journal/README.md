# Development journal

Notes on each step of development: what was done, the decisions made (and why), and gotchas hit
along the way.

- One file per step or topic: `{mm-dd-yy}-{title}.md`, e.g. `09-29-26-neon-setup.md`.
- Sections: **Summary**, **Decisions**, **Implementation**, **Gotchas**, **Next** (skip empty ones).
- Add a new entry rather than rewriting old ones; if a decision changes, say so in the new entry and
  link back.
