## dev/ folder

Development-only files (journal, smoke tests, one-off scripts, fixtures) live in `dev/`, not in
`src/`. List any new subfolder in `dev/README.md`.

## Development journal

After each step of work, add a note to `dev/journal/` named `{mm-dd-yy}-{title}.md` covering
decisions, implementation and gotchas. See `dev/journal/README.md` for the format.
